Consulta Pública de Veracidade Acadêmica

Ambiente público para conferência de registros acadêmicos e documentos emitidos. O CPF pode ser usado para localizar o registro, mas a consulta exige os dados de conferência e o código único de veracidade.

i Para proteger os dados acadêmicos, a consulta exige a combinação dos dados informados. O sistema retorna somente as informações necessárias para a conferência do registro ou documento. Não compartilhe seu CPF nem o código de veracidade publicamente.
